# MIUI 时间胶囊 · 参赛工程

粉丝自制怀旧互动作品，**非小米官方发布**。纯前端静态资源，无外链、无 SDK、无账号与联网请求。

## 交付物

| 文件 | 用途 |
| --- | --- |
| `miui-time-capsule.zip` | 提交包（21 KB，根目录 `index.html`，4 个文件） |
| `cover.png` | 发布页封面：1080×1440，3:4 竖版，544 KB |

## 发布信息（已定稿）

- **名称**：`MIUI 时间胶囊`
- **介绍标题**：`从 MIUI 1 滑到 HyperOS，测测你是几代米粉`
- **场景标签**：`知识可视化`

## 本地运行

```bash
cd ~/workspace/miui-time-capsule
python3 -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899/
```

## 提交步骤

1. 登录小米账号，进入活动页「立即创作」→ 创作中心「发布互动应用」。
2. 上传 `miui-time-capsule.zip`，上传 `cover.png` 作为封面。
3. 场景标签建议选 **知识可视化**（作品主体是横滑时间轴与年代场景复原）。
4. 勾选「参加小米浏览器 Vibe Coding 大赛」，完成邮箱验证与安全手机验证后提交。
5. 预览小视频选填；若制作，需 MP4、3:4 竖版、至少 1080×1440、短于 15 秒且不超过 5MB。

## 内容与合规说明

- 页面内已明确标注「粉丝自制怀旧互动 · 非小米官方发布」。
- 所有图形均为 CSS/SVG 手绘，不使用小米官方 Logo、截图或第三方素材。
- 不接入广告、统计、登录、云端、远程模型；图片保存与本地笔记均使用标准 Web API。
- 本地存储键统一以 `miui-capsule:v1:` 开头；「写给未来」内容只存本机，用户可删除。
- 结果卡为娱乐性质，不宣称官方认证。

## 已验证

- 10 张卡片与 10 个交互场景（拨号盘、云同步、图标切换、分身滑块、语音助手、超级壁纸、隐私开关、人车家连接、指纹解锁、本地胶囊）。
- 手机竖屏、PAD/PC 宽屏（≥760px）布局；触摸与鼠标拖拽横滑；键盘左右键切换。
- ZIP 自检：入口正确、4 个文件、21 KB、无绝对路径/`../`、无可执行文件与服务端脚本、无外部 URL。

## 已知限制

- 部分小米浏览器内嵌环境可能不支持 `a[download]`；此时结果页会提示长按卡片图片保存。
- 本地存储被清除后，进度与「写给未来」内容会消失；分享卡的文案仍可复制。
